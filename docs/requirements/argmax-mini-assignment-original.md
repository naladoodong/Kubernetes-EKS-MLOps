[시나리오 및 요구사항]
당신은 ArgMax Mini Backend Engineer 입니다. ArgMax Mini는 사용자가 데이터를 업로드하고, 선택한 데이터셋을 기반으로 AI 모델을 학습시킨 후, 학습된 모델을 통해 예측(추론) 결과를 제공하는 플랫폼입니다. 이 플랫폼은 다양한 모델을 관리하고 서빙할 수 있어야 하며, 지속적인 재학습과 모델 개선이 가능한 구조를 가져야 합니다.

[핵심 기능 요구사항]
- 사용자는 CSV 또는 Excel 형식의 테이블 데이터를 업로드할 수 있으며, 파일당 최대 2GB까지 허용됩니다.
- 사용자는 업로드된 데이터셋 중 원하는 항목을 선택하여, AI 모델 학습을 요청합니다.
- 사용자는 모델을 삭제하거나, 일정 기간 내에 복원할 수 있습니다.
- 한 명의 사용자는 여러 데이터셋을 등록하고, 여러 개의 모델을 생성 및 관리할 수 있습니다.
- 학습 완료 후에는 모델 성능 지표(예: 정확도, 정밀도 등)을 사용자에게 제공해야 합니다.
- 학습된 모델은 사용자 요청에 따라 추론 기능을 제공해야 하며, 이때 추론은 API를 통해 이루어지고, 모델마다 입출력 구조가 상이할 수 있습니다.
- 사용자는 기존 모델의 성능 개선을 위해 새로운 데이터를 추가하거나, 기존 데이터를 수정하여 재학습을 수행할 수 있어야 하며, 이때 모델 버전 관리가 되어야 합니다.
- 모든 학습 과정은 GPU 자원을 활용해야 하며, GPU 리소스의 효율적인 할당 및 관리가 가능해야 합니다.
- 모델 학습에는 최소 12시간에서 최대 24시간까지 소요될 수 있습니다. 따라서 장시간 실행되는 학습 작업에 대한 처리 방안을 고려해야 합니다.

[다운스트림(내부 사용자) 요구사항]
- ArgMax Mini는 ML Engineer 등 다운스트림 사용자(내부 사용자)가 존재하며, 이들은 고객의 업로드 데이터, 추론 요청 및 응답 데이터를 분석하여 모델 품질 향상 및 성능 개선을 위한 작업을 수행합니다.
- 다운스트림 사용자는 주로 고객 데이터 분석 및 모델 성능 최적화를 목적으로 데이터를 활용하며, 이 과정에서 대용량 데이터를 대상으로 하는 통계 쿼리 또는 분석 쿼리가 실행될 수 있습니다.


[과제 설명 > 설계 파트(총점 70점)]
해당 파트에서는 시나리오를 바탕으로, Kubernetes 환경을 전제로 한 시스템 아키텍처를 설계해주시기 바랍니다. 클라우드, 온프레미스, 또는 하이브리드 환경 중 가장 자신 있는 인프라 환경을 자유롭게 선택하여 구성하시면 됩니다. 데이터베이스, 저장소, 메시지 브로커 등 세부적인 기술 스택은 지원자가 판단하여 적절한 도구를 자유롭게 선택해 사용할 수 있습니다.
